• Switch input source: a new system function that switches between ABC and the other input source you use (Chinese, Japanese, Korean, Russian and more) directly, like Caps Lock, with no switcher on screen. Give it to Shift tapped alone, or any other key, in Custom Rules.
  • Win+Space: with the Windows Key group on, Win+Space switches the input source, as on Windows.
  • Paste a path: the ⌘L path box is gone; paste a path with Ctrl+Shift+G, in Finder and in open and save dialogs.
