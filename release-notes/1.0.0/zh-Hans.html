KeyBridge 的第一个正式版：把你在 Windows 上的快捷键和鼠标习惯带到 Mac。

  • Windows 快捷键：Ctrl+C、V、Z 等，Home 和 End，Ctrl+方向键按词移动，Alt+Tab、Alt+F4、Ctrl+Shift+Esc 和 PrtScn。按组开关，每一项都能修改，也能添加自己的规则。
  • Ctrl 或 fn：像在 Windows 上一样按 Ctrl，或者改用 fn，把 Ctrl 留给 Mac。在终端里，Ctrl+C 仍然是中断正在运行的程序。
  • 鼠标：侧键前进后退，Ctrl+滚轮缩放网页，滚轮方向和 Windows 一致，触控板不受影响。
  • 访达：Delete、F2 和回车的作用和 Windows 一样，Ctrl+X、Ctrl+V 移动文件，右键菜单可以新建文档、拷贝路径或在终端中打开。
  • 窗口：⌥+方向键把最前面的窗口吸附到半屏或铺满屏幕，就像 Windows 上的 Win+方向键。
  • 剪贴板历史：⇧⌘C 显示最近拷贝过的内容，就像 Win+V。
  • 打开和存储对话框：Ctrl+G 跳到访达里正打开的文件夹，Ctrl+Shift+G 列出最近和收藏的文件夹。
  • 支持 English、简体中文和日本語。从这个版本起，KeyBridge 会自动保持最新。
