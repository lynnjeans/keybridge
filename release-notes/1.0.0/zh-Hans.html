• Windows 快捷键：把 Windows 的习惯原样挪到 Mac 上，例如 Ctrl+C/V/Z 复制、粘贴、撤销，Home/End 跳到行首行尾，Ctrl+←/→ 按词移动，Alt+Tab 切换应用。
  • 鼠标：反转滚轮方向，自定义侧键功能（例如前进后退），Ctrl+滚轮缩放网页。
  • 访达：Ctrl+X、Ctrl+V 移动文件等 Windows 习惯，右键菜单可以新建文档、拷贝路径或在终端中打开。
  • 窗口：⌥+方向键把最前面的窗口吸附到半屏或铺满屏幕，就像 Windows 上的 Win+方向键。
  • 剪贴板历史：⌥V 显示最近拷贝过的内容，就像 Win+V。
  • 打开或保存文件时：Ctrl+G 跳到访达里正打开的文件夹，Ctrl+Shift+G 列出最近和收藏的文件夹。
  • 支持 English、简体中文和日本語。从这个版本起，KeyBridge 会自动保持最新。
