• Windows のショートカット：Windows の使い方を、そのまま Mac へ。
  • マウス：ホイールの向きの反転、サイドボタンの機能の割り当て（戻る・進むなど）、Ctrl+スクロールでページの拡大・縮小。
  • Finder：Ctrl+X と Ctrl+V でのファイル移動など Windows の使い方に対応。右クリックメニューから新規書類の作成、パスのコピー、ターミナルで開くこともできます。
  • ウインドウ：⌥+矢印キーで最前面のウインドウを画面の半分に寄せたり、画面いっぱいに広げたりできます。Windows の Win+矢印キーと同じです。
  • クリップボード履歴：⇧⌘C で最近コピーしたものを表示します。Win+V と同じです。ショートカットは ⌥V などに変更できます。
  • ファイルを開く・保存するとき：Ctrl+G で Finder で開いているフォルダへ移動し、Ctrl+Shift+G で最近使ったフォルダとお気に入りを一覧できます。
  • English、简体中文、日本語に対応。このバージョンから、KeyBridge は自動で最新の状態を保ちます。
