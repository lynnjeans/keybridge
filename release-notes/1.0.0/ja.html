KeyBridge の最初のリリースです。Windows のショートカットとマウスの使い方を、そのまま Mac で。

  • Windows のショートカット：Ctrl+C・V・Z など、Home と End、Ctrl+矢印キーで単語単位の移動、Alt+Tab、Alt+F4、Ctrl+Shift+Esc、PrtScn。グループごとにオン・オフでき、どれも変更したり自分のルールを追加したりできます。
  • Ctrl か fn か：Windows と同じように Ctrl を押すことも、代わりに fn を使って Ctrl を Mac 用に残すこともできます。ターミナルでは Ctrl+C はこれまでどおり実行中のプログラムを止めます。
  • マウス：サイドボタンで戻る・進む、Ctrl+スクロールでページを拡大・縮小。ホイールは Windows と同じ向きになり、トラックパッドはそのままです。
  • Finder：Delete、F2、Enter が Windows と同じように働き、Ctrl+X と Ctrl+V でファイルを移動できます。右クリックメニューから新規書類の作成、パスのコピー、ターミナルで開くこともできます。
  • ウインドウ：⌥+矢印キーで最前面のウインドウを画面の半分に寄せたり画面いっぱいに広げたりできます。Windows の Win+矢印キーと同じです。
  • クリップボード履歴：⇧⌘C で最近コピーしたものを表示します。Win+V と同じです。
  • 開く・保存ダイアログ：Ctrl+G で Finder で開いているフォルダへ移動し、Ctrl+Shift+G で最近使ったフォルダとお気に入りを一覧できます。
  • English、简体中文、日本語に対応。これからは KeyBridge が自動で最新の状態を保ちます。
