• Open at Login: KeyBridge starts when you log in. New installs have it ticked in the setup guide; if you already use KeyBridge, switch it on on the Overview page.
  • Each keyboard its own way: a MacBook's keyboard and an external PC keyboard can each press the Ctrl shortcuts and Win/Alt their own way, on the Shortcuts page. A PC keyboard uses Ctrl and its own Win key as soon as it is plugged in.
